使用方式

3 步开始追踪

1

安装 Skill

从 GitHub 克隆 Skill 到本地 OpenClaw 工作目录，支持 Claude Code、OpenClaw 等 AI Agent。

git clone https://github.com/wbbk/gti-skill.git ~/.openclaw/skills/gti-skill
2

配置 Token

设置 GitHub Token 和飞书多维表格 API，实现自动写入和推送。

export GITHUB_TOKEN='your-token'
export FEISHU_APP_TOKEN='your-feishu-app-token'
3

定时抓取

配置 Cron 定时任务，每天自动拉取最新数据到飞书表格，随时掌握 AI 赛道动态。

bash github-trending-intelligence.sh --top 100
